- **The built and planned marks are true.** Ten built and five planned marks sampled, all true; the deferred levers carry observable triggers (C).

## What did not hold, and what changed today

The pattern across the seats: a claim that became code or a decision survived; a claim that stayed a claim drifted, and the plan stated the opposite of the code in four places a builder of M1b and M1c would act on. 1. **Post-run invariant severity.** The plan, its gates table, its failure matrix, the guards ledger, the harness page, and the test strategy said a violation flips the run to `failed`; the code makes five of seven built invariants warnings that close the run `partial` with no notification, and the `degraded` status the plan named exists nowhere. Version one had carried the split with a sixty-day clock the code never had. Now stated by severity, with the promotion question pending Wes (A2 #1, B2 F1, E1 F1 and F2, E2 #3).
2. **The content-state machine.** The plan read an unknown removal category as a moderator removal; the code fails closed to `removed_by_reddit`, the ingest panel's ruling. The deleted-link-post hold from the adversarial review was dropped in the rewrite and the sentence left in its place re-derived the bug. Now restated in the code's rule order (B1 #1 and #2, E1 F9).
3. **A run with no collectable source.** The plan said it is refused loudly; the fix it cites makes it `partial` with a warning and an error from `doctor`. Corrected (E2 #2, E1 F11).
4. **Backup retention.** The plan, the decisions log, and the runbook stated a per-run copy, a retention sweep, an interim bound, and a compliance canary in the present tense; none exists, and the only copies are pre-migration ones pruned by count. Split into decided and built, with the per-run copy bound to reconcile at M1c in the same change as the sweep (E2 #1, E1 F6, C #6 and #7).

8. **Tranche B's specification.** The `probe` command was one argument where the probe plan needs five sub-modes, the probe day had no checklist and its plan was frozen inside a record, fixture scrubbing was answered three ways, the cassette directory was undecided, and a live test could not pass even with credentials.
