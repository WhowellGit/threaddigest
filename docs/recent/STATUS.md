- The memory snapshot is private (D-35): it lives outside the repository in the folder THREADDIGEST_PRIVATE_DIR names, is in no commit, and a missing folder is red. - The memory home is the repo-keyed directory; the Desktop-keyed one holds a pointer only, and `make check` goes red if a second home grows topic files again.
- Sessions start in `~/repos/insightminer`; a session started elsewhere runs without the hard-block hooks.
- The three redacted retrospectives keep the earlier project's own register ids on purpose; the identifier gate excludes that folder and nothing else.
- The read-before-touch hook stays in `log` mode until its ledger is reviewed on 2026-09-28; flipping the mode is a reviewed commit, never a hand edit.
- The hook-settings gate requires every script under `tools/hooks/` to be registered; a new hook script turns `make check` red until a human registers it.
- A second live session in this checkout works in a git worktree until the one-session guard lands (incident of 2026-09-14).
- `main` receives only a tree `make check` stamped green: stage everything, run the check, commit, switch, merge fast-forward; untracked files block the stamp until they are added.
- The code-health ceilings move only through `make ratchet-bump` and `make ratchet-loosen`; a relaxation past its date is red until tightened or re-approved.
- The plan is corrected in place between versions and rewritten as a version once annotations accrete; retired sections get a home in the decisions log in the same change; the harness page's inventory is regenerated, never typed; a changed fact is swept through the `docs-sweep` skill, and a rewritten document gets a targeted rewrite of its section, never an appended note or a dated annotation. A build that deviates from a mechanism the plan names changes the plan in the same commit, with the reason; a planned identifier belongs in a table with a status cell, not in prose.
- Post-run invariants carry a severity: only a failure closes a run `failed`; a warning closes it `partial`, and the launchd wrapper never notifies on `partial`. Index membership is a failure since 2026-09-16; do not move a severity without a ruling in the decisions log.

No cassette is recorded until the recording filters in `tests/adapters/conftest.py` have been read again; a committed cassette is permanent history.
